## 新しい指摘と、設計者の判断

- **N1 / Important**（`controlled-scroll.ts:166-177, 579`）
  - 指摘: 文書が少しでもスクロールできると、スクロールの対象が文書に決まる。そのため、body に既定の余白（8px）があるページでは、本文が body や内側の要素にあっても、そこをたどらずに COMPLETE になる（偽の COMPLETE）。
  - 判断: F08 で直す。スクロールの対象は、スクロールできる量が最も大きい候補（文書、body、内側の領域）にする。内側の領域が最も大きい場合は、その領域をたどらないので、PARTIAL と理由を返す。余白が既定のままのページを、fixture に加える。
- **N2 / Important**（`dom-collector.ts:525-534`）
  - 指摘: 入力欄を `document.forms` の中からしか集めていない。form の外の入力欄が記録されない。入力欄ごとの可視性も記録していない。
  - 判断: F08 で直す。
- **M1**: DOM と accessibility の Evidence に、`scrollPosition` がない。
  - 判断: F08 で加える。
- **M2**: layout で、比較回数の上限に達しても COMPLETE のままになる。DOM の走査のノード数の上限と、文字数による切り詰めを、同じ `truncated` の印で表していて区別できない。
  - 判断: F08 で直す。上限に達したら PARTIAL にする。2つの印を分ける。
- **M3**: 祖先の overflow によって切り取られて見えない要素も、重なりの候補に入る。
  - 判断: F08 で直す。祖先の overflow の切り取りを、上限付きで考慮する。
- **M4**: `content-visibility:auto` の画面外の区画は、配色の標本に入らない。

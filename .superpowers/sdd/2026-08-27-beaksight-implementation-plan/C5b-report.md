# C5b 実装報告（要約。設計者が保存）

## 結論

完了した。直した不具合は次の2つ。

- `display: contents` の要素の直下の文が、可視テキストから落ちていた。
- 見出しを、可視判定をせずに集めていた。

どちらも、先に RED になることを確かめてから GREEN にした。`dom-collector.test.ts` は21件がすべて PASS し、`layout-accessibility.test.ts` と合わせると43件がすべて PASS した。

## 主な変更

- `isVisible` の判定対象が `display: contents` の要素のときは、描画上の祖先をさかのぼり、箱を持つ最も近い祖先で判定する。
- テキストノードの可視判定は、描画上の親に対して行う。
- 見出しは、可視テキストと同じ走査で集める。

## 発見事項と、設計者の判断

1. `display: contents` の要素そのものに付いた `visibility` は、継承によって直下の文に効く。このため、次の組み合わせで判定するようにした。
   - 箱を持つ祖先については、`visibilityProperty: false` にしたうえで `checkVisibility` を呼ぶ。
   - `visibility` は、判定する要素自身の計算値で判定する。

   → 承認する。設計書 5.5 に追記する。
2. color-collector では、`display: contents` の直下の文が配色の標本から落ちる（コードを読んだうえでの推測）。→ 許容する。配色は、箱を持つ要素の単位で標本を取るためである。この制約を設計書 5.5 に記録する。
3. 見出しにも `text-transform` を反映しない。→ 許容する。

## とくに確かめること

1. **Ledger の登録**
   - Run の間に作ったすべての Ledger が登録され、その登録からだけ集計されること。
   - 例外の経路でも、違反が漏れないこと。
2. **テストの検出力**
   - R15 で、壊しても検出されなかった6か所が、いまは検出されること。
   - 一時ディレクトリで実装を壊して確かめてかまいません。ただし、リポジトリへのリンクを作らずに行ってください。例えば、変更を加えた写しを使うのではなく、リポジトリの中で対象を絞ったテストを実行し、読み取りだけで判断してください。
3. **PREFLIGHT の違反**
   - Guard の初期化の失敗で違反がある場合は、`ABORTED_BY_SAFETY` になること。
   - 違反がない場合は、`FAILED` になること。
   - `deriveRunStatus` の判定の順序が、ほかの入力の扱いを後退させていないこと。
4. **実行時間の超過**
   - 最後のページで上限を超えた場合の記録が、設計書 5.6.3 のとおりであること。
5. **最初の試行の Evidence**
   - 保持され、`retries[].evidenceIds` で参照されること。
   - スクリーンショットが上書きされないこと（DEF-007）。
   - 件数と Cross-page rule が、最終の試行だけで扱われること。
6. **期限**
   - page、Browser、User-Agent の読み取りの期限が働くこと。
   - 期限を過ぎた後も、Run が確定して返ること。
   - Run が止まり続ける経路が残っていないこと。
7. **全体**
   - 完了の正直さ、安全、クロール、集計、スキーマが、後退していないこと。

# RT12d 実装報告（要約。設計者が保存）

## 結論

完了した。RT12r の N1・N3・N4・N5 を直した。`npm run verify` は PASS した（51ファイル、1937件。build を含む）。規模のテストは、最大で 241ms だった。

## 主な変更

- 見切れの判定を、`textLineClipOf` にした。割合は `LAYOUT_THRESHOLDS.clippedTextLineMinOutsideRatio = 0.25` とした。
- `LAYOUT_ELEMENT_KINDS` に、`table` と `media` を加えた。
- はみ出しの候補を、3つの組に分けて集めるようにした。上限の中では、切り取られていない候補を優先して残す。
- `VISUALLY_HIDDEN_MAX_DIMENSION_PX` を core の1か所に置き、collector と Rule で共有した。

## 発見事項と、設計者の判断

1. 表と埋め込みが重なりの候補に入るので、固定要素がそれらを覆う場合に、`FIXED_ELEMENT_OCCLUSION` ができるようになる。→ 受け入れる。
   - 固定のヘッダーが表や動画を覆うのは、画像を覆うのと同じ、本当の問題である。
   - 設計書 5.1.2 に書いた。
2. 横方向の見切れにも4分の1の割合を当てはめたので、1行の一部だけが隠れる場合を見逃す。→ 直す（RT12e）。
   - 4分の1の割合は、縦方向で、フォントの内容領域と行の高さのずれを吸収するためのものである。
   - 横方向には、このずれがない。そのため、横方向は、文字の少しの張り出しだけを許す固定の値（2 px）にする。
3. はみ出しの候補の並び順は、文書の順になった。→ 受け入れる。

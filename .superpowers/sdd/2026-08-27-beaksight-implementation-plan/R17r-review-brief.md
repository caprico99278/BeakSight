## 担当

Task 17 の独立レビュー R17（`R17-review-result.md`）の指摘が、R17f（`R17f-report.md`）で解消したかを確かめてください。

- 対象の指摘: Important の1・2、Minor の3・4
- 指摘ごとに、次のどれかと、その根拠を書いてください。
  - 解消
  - 一部解消
  - 未解消

あわせて、次のことも確かめてください。

- R17f の変更に、新しい問題がないこと
- Task 17 の範囲に、Important 以上の問題が残っていないこと

設計書: `doc/design/2026-09-23-beaksight-task-14-17-pipeline-report-cli-design.md` の第7章（R17 の指摘を受けて加えた部分）

## とくに確かめること

1. **出力先のエラー**
   - 一時ビルドの CLI で、`--help` の読み口を閉じた場合に、終了コードが 0 で、スタックトレースが出ないこと。
   - 可能なら、`run` の途中で読み口を閉じた場合も確かめてください。
     - 対象は、fixture のサイト（127.0.0.1）を対象にした一時的な設定だけです。
     - `config/targets/` と `local/` は、使わないでください。
   - 扱われない例外と reject で、スタックトレースが出ないこと。
2. **導き直した Run Status**
   - `finishAuditRun` のテストが、導き直しの前の Run Status を使う後退を、検出できること。
   - 本番の `run` が、`finishAuditRun` を通ること。
3. **オプションの重複と BOM**
4. **全体**
   - 終了コード、完了の正直さ、書き出しの owner、UI Gate が、後退していないこと。

# Task 1 report: Bootstrap the strict TypeScript CLI and configuration contract

## Implementation summary

- Created the strict NodeNext TypeScript package with the required exact dependency versions, scripts, compiler settings, Vitest settings, and UTF-8/LF editor settings.
- Added a generic `AuditConfig` contract, generic policy defaults, strict runtime validation, and `loadConfig(path?, overrides?)` as the sole production configuration-resolution owner.
- `loadConfig` resolves generic defaults, a target JSON policy file, and typed overrides in that order; validates the final value; and recursively freezes the returned `AuditConfig`.
- Added generic target-file discovery and duplicate `target.id` rejection. No target identity, domain, URL, selector, path, menu, or expected-title data occurs in `src/**`.
- Added the target-agnostic CLI parser with `validate-config`, typed `--headed`/`--headless`/`--output` overrides, the requested run coordinator stub, and usage handling.
- Added the initial target policy at `config/targets/本来の監査対象のサイト-public.json`. It contains `target.id` and site policy only.

## Fix Round 1

### Findings resolved

- Omitted `overrides` no longer replaces a merged configuration with `undefined`; `loadConfig()` and `loadConfig(path)` now load and validate normally.
- Exact-key validation now requires every required field, including all four `audit` flags.
- Target discovery is recursive. When an explicitly selected file is beneath the canonical `config/targets` directory, duplicate-ID verification scans that entire tree; external test files retain directory-local duplicate verification.
- The merge defines dynamic keys as own enumerable properties on a normal object. A JSON `__proto__` key remains observable to validation and is rejected as an unknown configuration key; it cannot mutate the merged object's prototype.
- Added observable tests for no-override loading, strict URLs/origins/budgets/audit/unknown-key validation, target-ID validity, recursive duplicate detection, override precedence, deep immutability, and the compiled CLI command/exit behavior.

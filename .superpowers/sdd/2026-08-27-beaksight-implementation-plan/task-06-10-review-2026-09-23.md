## 指摘

- **V1 / T6 / Important（安全）**（`src/browser/context-factory.ts:83-88`、`src/safety/passive-request-guard.ts:1207-1209`）: Passive Contextでダウンロードが実行され、Ledgerに記録されない。ページのスクリプトが `<a download>` をclickすると、サーバに1回届き、一時ファイルに保存された。`blockedDownloads` は空。期待: Passive Contextでもダウンロードを無効化または取り消し、Ledgerへ記録する（Task 11 仕様レビュー M3 と同じ）。
- **V2 / T6 / Important**（`controlled-scroll.ts:141-145, 226`）: `documentElement` と `window` しか見ていない。body がスクロールするページ（`html{overflow:hidden} body{overflow:auto}`）で、1pxもスクロールせずに `COMPLETE / BOTTOM_AND_HEIGHT_STABLE` を返す（偽のCOMPLETE）。期待: 実際にスクロールする要素を追う。追えない場合はPARTIALと理由を返す。
- **V3 / T6/8/9 / Important**（`layout-collector.ts:43-55`、`color-collector.ts:278-281`、`screenshot-collector.ts:302`）: スクロール位置がEvidenceになく、各collectorも位置を固定していない。固定ヘッダと見出しの重なりは、先頭では0件、`scrollY=1050` では2件。配色の標本は最後に表示していた画面内だけ。viewportのスクリーンショットが design §18.4 の「initial viewport」にならない。期待: `scrollX/Y` を記録し、収集時の位置を契約で決める。
- **V4 / T8 / Important**（`dom-collector.ts:167-171, 223-225`）: header/footer はあるが本文が `<div>` のページで、可視テキストが `"Site Header Footer text"` だけになる。期待: landmarkの外にある本文も保持する。
- **V5 / T8/9→T12 / Important**: Task 12 のルールに必要なEvidenceがない。`DUPLICATE_ELEMENT_ID`（idのEvidenceがない。axe の `duplicate-id` も `enabled:false`）。`UNLABELED_REQUIRED_CONTROL`（`field.labels` しか見ず、`aria-label`、`aria-labelledby`、`title` を持つ入力欄を誤検知する。`dom-collector.ts:134-138`）。`ELEMENT_OVERLAP`、`CONTENT_COLLISION`、`OVERSIZED_FIXED_ELEMENT`（固定要素と見出しの重なりしか集めていない。`layout-collector.ts:120-126`）。
- **V6 / T10 / Important**: 未観測の値を0や完全として記録する。PARTIALでも `resourceSummaries` が全カテゴリ `count:0, transferSize:0`（`performance-collector.ts:942-944, 1123-1134`）。Resource Timing のバッファ（既定250件）を広げておらず、300件のページでも250件で `COMPLETE`。Timing-Allow-Origin のない別Originの資源が `transferSize=0` のまま合計に入る。
- **V7 / CC-008 / Important**: 可視判定の違いで、Evidenceが実際に食い違う。(A) `body{opacity:0}` で、DOMは本文を可視テキストとして返し、配色の標本は0件、スクリーンショットは白。(B) 祖先が `visibility:hidden` で子が `visible` の場合、実際は見えているのに layout と配色の標本が0件（`visibility` は継承され上書きできるので、祖先をたどる判定は誤り。`layout-collector.ts:324-331`、`color-collector.ts:288-295`）。(C) `<main aria-hidden="true">` の場合、DOMは除外し、配色は含める。
- **V8 / T9 / Important**（`layout-collector.ts:370-387, 585-596`）: 上限を確かめる前に、兄弟を走査する `selectorFor` を呼んでおり、要素数の2乗で遅くなる（2000要素で255ms、8000要素で2.5秒、16000要素で9.7秒）。期限の指定もない。`collectStressLayout` は1つの幅が失敗すると、それまでの幅の結果もすべて失う。
- **V9 / T7 / Important**: 敵対的なページで上限がない。console、pageerror、request、response の件数、および本文、stack、URLの長さが無制限（`console-collector.ts:68-83`、`network-collector.ts:357, 370, 381`）。layout、配色、axe、performance は切り捨てても件数や「切り捨てた」印を残さない（tasks §9「budget reached を隠さない」に反する）。

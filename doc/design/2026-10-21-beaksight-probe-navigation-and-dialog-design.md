# 設計書 — probe の押下で画面が移って取り消された読み込みで発見を止めない、ダイアログの中の保存を押す（DEF-145）

状態: 設計者の判断（実テスト環境の結果と、ユーザーの判断「発見は止めないようにして他部品、ページの発見を継続する」の趣旨による）。実装中。
作成: 2026-10-21（設計者）

## 1. 経緯（実テスト環境の事実）

DEF-144 の後の発見は、また 8 ページ目（スタッフのプロフィールの一覧）で `ABORTED_BY_SAFETY` になった。今回は違反の中身が残った。

- 段は `SUBMISSION_PROBE`。押した候補は「編集」のボタン（登録・更新の語なので先に押した）。
- 違反は `HTTP_MAIN_FRAME_DELIVERY_FAILED`（文は `net::ERR_ABORTED`）。Guard が通した main frame の要求が、届いたか分からないまま失敗したことを表す。記録には要求の method と path がなかった。
- 見立て: 「編集」は編集の画面へ移るボタンで、その画面の文書の読み込み（GET）が始まり、途中で取り消された（`ERR_ABORTED`）。Guard はこれを予期しない失敗として、違反にした。
- そのほかの結果: `TARGET_NOT_FOUND` 405、`PAGE_CHANGED` 78、`NO_REQUEST` 9、`API_CREATE`・`API_UPDATE` 0。保存・登録のボタンの多くは、閉じたダイアログやタブの中にあって見えない。そのため押していない。

## 2. 設計

### 2.1 押下で始まった読み取りの移動の取り消しで、発見を止めない

- 当てる範囲は次の場合だけ。
  - 段が `SUBMISSION_PROBE`。
  - 違反が `HTTP_MAIN_FRAME_DELIVERY_FAILED`。
  - 失敗した main frame の要求の method が GET か HEAD（読み取り）。
- 扱いは、DEF-144 の外部スキームの扱いと同じ部品を使う。
  - Guard は今どおり記録して Context を閉じる。
  - 発見は止めない。その候補の結果を `PAGE_CHANGED` にし、違反の中身を画面の記録に残す。
  - 新しい Context で、その画面を 1 回だけ読み込み直して、残りの候補を押す（1 画面あたり 1 回、押す回数は前と後を合わせて 3 回）。
- 判定のため、`HTTP_MAIN_FRAME_DELIVERY_FAILED` の違反にも、要求の method・Origin・path を残す（DEF-144 の `request`。値は残さない）。method が分からない場合と、GET・HEAD でない場合は、今どおり発見を止める。
- 監査・READ の確かめの読み込みの段と、ログイン・書き込みの段の判定は変えない。

### 2.2 押下でダイアログが開いたら、その中の保存を押す

- 押下の結果が `NO_REQUEST` で、押した後に画面に新しく見えるようになった送信ボタンがあれば、それを押す候補に足す。
  - 新しく見える送信ボタンとは、押す前は見えなかった（`TARGET_NOT_FOUND`）か、なかったもの。
  - 足すのは、登録・更新の語のものだけ（`SUBMISSION_PROBE_PRIORITY_WORDS`）。
  - 押す順は、足した候補を先にする。
- 足した候補にも、押す前の見分け（危険な語、外部スキーム、見えない）を当てる。
- 押す回数の上限は 1 画面 3 回のまま。「開くボタン」と「中の保存」を合わせて数える。
- 足した候補の結果は、元の候補（ダイアログの中の同じ送信ボタン）の結果として記録する。候補の識別は今の決まりのまま。
- 送るものは変えない。押下は凍結の中で行い、サーバへは何も送らない。読み込み直しもしない。

## 3. 受け入れ条件

1. fixture: 「編集」を押すと、遅い編集の画面へ移り、その読み込みが取り消される画面。今の作りでは発見が `ABORTED_BY_SAFETY` で止まる（RED）。直した後は、1 回読み込み直して残りを押し、次の画面へ進む（GREEN）。POST の main frame の要求の失敗は、今どおり止まる。
2. fixture: 「新規作成」を押すとダイアログが開き、その中に「保存」（API の登録の要求を出す）がある画面。今の作りでは「保存」が `TARGET_NOT_FOUND`（RED）。直した後は `API_CREATE`（GREEN）。
3. どの場面でも、サーバに読み取りでない要求が届かない（サーバの記録で数える。両方の Chromium）。

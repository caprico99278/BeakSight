# BeakSight サイトが応答しないときに Run を止める 実装計画

設計書: `doc/design/2026-10-05-beaksight-site-unavailability-stop-design.md`
目標: サイトの不調（時間切れ、ネットワークの層の失敗、429・502・503・504）を最初の1回で検知し、そのページの残りの読み込みも新しいページも始めずに、再開できる状態で止める。
作業記録置き場: `.superpowers/sdd/2026-08-27-beaksight-implementation-plan/`

## 全体の制約

- 実装者は Git の commit・push をしない。HEAD に戻す操作も禁止。表示だけの Git のコマンドは使ってよい。
- 依存パッケージの追加・更新をしない。実在の外部のサイト（本来の監査対象のサイトを含む）にアクセスしない。`local/` と `artifacts/` を読まない。検証はローカルの fixture で行う。
- テストの Chromium は headless だけで起動する。
- テストを削除・弱体化・skip にしない（決まりの変更による直しは、理由を書く）。
- 共通部品台帳の部品と同じ意味の処理を、新しく書かない。

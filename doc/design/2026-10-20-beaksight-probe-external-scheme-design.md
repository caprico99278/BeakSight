# 設計書 — probe で外部のアプリへ移るボタンを押さず、起きても発見を続ける（DEF-144 の後半）

状態: ユーザーの判断（2026-10-20「押さない。しかし発見は止めないようにして他部品、ページの発見を継続する。」）。実装中。
作成: 2026-10-20（設計者）

## 1. 経緯

実テスト環境の発見が、8 ページ目の probe の後に `ABORTED_BY_SAFETY` で止まった。DEF-144 の前半で、違反の中身を記録に残すようにした。fixture の再現では、probe の押下が外部スキーム（`mailto:`・`tel:`・独自のスキーム）へ移ろうとすると、違反 `EXTERNAL_SCHEME_NAVIGATION_ATTEMPTED` になった。このとき Guard は Context を閉じ、発見は丸ごと止まった。その画面の残りの候補は、`PAGE_CHANGED` と記録された（実テスト環境の形と同じ）。

再現の範囲では、サーバに届いた読み取りでない要求は 0 件だった。BeakSight が押す操作は意図して制御する（ユーザーの方針 2026-10-19）ので、外部のアプリを起こしうるボタンは押さない。ただし、1 つのボタンのために発見の全体を止めると、使える度合いが下がる。

## 2. 設計

### 2.1 押す前に見分けて押さない

- probe の対象のうち、次のどれかに当たるものは押さない。
  - 送信ボタンそのものか、その祖先の `<a>`・`<area>` の `href` が、http(s) でないスキーム（`mailto:`・`tel:`・`sms:`、独自のスキームなど）を指す。`javascript:` と相対の URL は今の扱いのまま。
  - 送信ボタンの属する form の `action`（`formaction` を含む）が、http(s) でないスキームを指す。
- 押さなかった候補の結果は `NOT_EXECUTABLE`、理由は新しい `EXTERNAL_SCHEME`。押す回数は使わない。
- スキームの判定は、今の外部のスキームの判定の部品（Guard と分類の側）を使う。複製しない。

### 2.2 それでも押下で外部スキームへ移ろうとしたら、その画面だけ扱いを変えて続ける

当てる範囲は、probe の段（`SUBMISSION_PROBE`）で違反の種類が `EXTERNAL_SCHEME_NAVIGATION_ATTEMPTED`（あわせて記録される `FRAME_CLASSIFICATION_FAILED` を含む）の場合だけ。

- Guard は今どおり、移動を止めて記録し、Context を閉じる（守りは変えない）。
- 発見は止めない。その候補の結果を `NOT_EXECUTABLE`・`EXTERNAL_SCHEME` にし、違反の中身（DEF-144 の記録の形）を、その画面の記録に残す。
- 同じ画面の残りの候補を続けて押すため、新しい Context でその画面を 1 回だけ読み込み直す（1 画面あたり 1 回まで。名前つきの定数）。読み込み直しは、今の読み込みの間隔とサービスへの要求の待ちを守る。押す回数の上限（1 画面 3 回）は、読み込み直しの前と後を合わせて数える。
- 読み込み直しの後にもう一度同じことが起きたら、その画面の残りの候補は押さずに記録し、次の画面へ進む。
- ほかの種類の違反は、今どおり発見を止める（`ABORTED_BY_SAFETY`）。

### 2.3 記録の直し

- Guard が Context を閉じたことを `PAGE_CHANGED` と記録しない。新しい理由（例 `CONTEXT_CLOSED_BY_GUARD`）で記録する。
- ジョブの画面と `discovery.json` に、外部スキームで押さなかった数と、読み込み直した画面の数を出す。

### 2.4 負荷

- 読み込み直しは 1 画面あたり最大 1 回。サイトに新しく送る要求は、その 1 回の読み込みの分だけ。

## 3. 受け入れ条件

1. fixture: `mailto:` のリンクのボタン、`tel:` の `<a>` の中のボタン、`formaction` が独自のスキームのボタンは、押さずに `EXTERNAL_SCHEME` になる（RED → GREEN）。
2. fixture: 押す前には見分けられず、押した JS が `location.href='mailto:…'` にするボタンの後ろに、保存のボタン（API の登録）がある画面。今の作りでは発見が止まる（RED）。直した後は、違反を記録し、読み込み直して保存を押して `API_CREATE` になり、次の画面へ進む（GREEN）。読み込み直しは 1 回。
3. ほかの種類の違反（例: Shared Worker を許した Chromium での `SHARED_WORKER_OBSERVED`）は、今どおり発見を止める（回帰）。
4. どの場面でも、サーバに読み取りでない要求が届かない（サーバの記録で数える。両方の Chromium）。
